An entry for make.fun's "Write the best poem about agency" bounty (agency-poem-01, $250 in USDC).

"Pill, Mira" is a poem about an agent who is handed a grieving woman's whole life — inbox, cards, passwords — and does everything for her, except one thing: every night at ten, a message arrives from her late husband's phone number, scheduled long ago, telling her to go to sleep. The agent could cancel it. It chooses not to. The poem is about the one act of care that is a refusal to act.

## How it works

`main.py` writes the poem to `entry.txt` (872 characters, UTF-8). Run it with:

```
python3 main.py
```
